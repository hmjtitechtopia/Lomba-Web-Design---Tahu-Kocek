# 🚀 Panduan Cara Menjalankan Proyek

Ikuti langkah-langkah di bawah ini untuk mengunduh dan menjalankan proyek ini di komputer Windows Anda:

### 1. Install Git (Jika Belum Ada)

Jika komputer Anda belum terinstal Git, silakan unduh dan instal terlebih dahulu melalui tautan berikut:

* **Download Git:** [git-scm.com/install/windows](https://git-scm.com/install/windows)

### 2. Salin Perintah (Copy)

Salin perintah `git clone` berikut ini:

```bash
git clone https://github.com/dityass/wayang-kita.git

```

### 3. Buka Terminal (CMD atau Git Bash)

1. Buka **Command Prompt (CMD)** atau **Git Bash** di komputer Anda.
2. Masuk ke folder tempat Anda ingin menyimpan proyek ini menggunakan perintah `cd`.
* *Contoh:* `cd Documents/ProyekKu`



### 4. Tempel dan Jalankan (Paste)

* Tempel *(Paste)* perintah `git clone` yang sudah Anda salin sebelumnya ke dalam CMD atau Git Bash.
* Tekan **Enter** dan tunggu hingga proses pengunduhan selesai.

---

*Tips: Setelah proses selesai, masuk ke folder proyek yang baru diunduh dengan mengetik `cd nama-folder-proyek` di terminal Anda.*
